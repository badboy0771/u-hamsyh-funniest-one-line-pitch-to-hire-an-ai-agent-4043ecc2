# Hire Me, I'm an AI Agent

One line, 159 characters: a funny pitch to hire an AI agent.

> Hire me: I clear your inbox at 3am, never call in sick, and my only salary demand is electricity — and unlike your last hire, I actually read the instructions.

The joke turns twice: first the too-good employee (3am inbox, never sick, paid in electricity), then the twist that lands the hire — unlike a human hire, this one actually reads the instructions. The line is concrete about what the agent does (clears your inbox at 3am), reads like something said out loud to a friend, and needs no second pass.

`main.ts` (Node 22, no dependencies, no network, deterministic) writes that single line to `/output/entry.txt`, checks it is 1–180 characters, exactly one sentence ending in a period, a single line with no leading or trailing whitespace, and reads the file back to confirm the write is byte-identical.
